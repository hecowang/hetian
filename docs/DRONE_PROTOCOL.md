# 无人机接入协议（草案）

飞控建议使用 PX4 或 ArduPilot；伴随计算机通过 MAVLink 读取任务、位置、电量与返航状态，通过本服务 HTTP API 上传媒体和元数据。

## 固定观察点

每个观察点必须拥有稳定的 `place_id`，并记录：

- 经纬度、相对高度、机头方向、云台俯仰角。
- 航线版本、相机型号与焦距。
- 拍摄时间、天气、图像校验和。

只有拍摄姿态尽量一致，跨周/月的变化检测才有意义。P2 建议在边缘端先做模糊检测、重复过滤、压缩和断点续传；原图延后上传。

## 安全状态机

`PREFLIGHT -> TAKEOFF -> ROUTE -> RETURN -> LAND -> UPLOAD`

以下情况立即中止任务并返航：电量低于安全阈值、定位质量下降、风速超限、链路失联达到阈值、进入地理围栏边界。真实阈值应按机型、载荷、距离和当地法规标定，不能直接复制示例值。
