# 产品定义

## 一句话

故乡守望是一套“无人机 + 长期影像档案 + AI”的远程故乡陪伴产品。

## 核心用户

长期在外工作、求学或定居，无法经常回乡，但关心老家日常变化的人。

## 要保存的不是景点，而是关系

- 田野今年种了什么、什么时候变黄。
- 老房子的屋顶、院子和门前小路有没有变化。
- 门口那棵树长高了多少，什么时候开花落叶。
- 村口、河流和道路随着季节与建设如何变化。
- 家人愿意分享的生活痕迹，而非持续监控。

## MVP 成功标准

- 同一固定观察点能够每周稳定产生一组可比照片。
- 用户可在 30 秒内看到本周新变化。
- 弱网中断后不会丢失原始影像。
- 任何自动飞行都能安全返航，人工可随时接管。

## 暂不做

- 不把农业病虫害巡检作为首要定位。
- 不在 MVP 阶段承诺无人值守跨季节运行。
- 不默认拍摄邻居院落、人员身份等隐私内容。
